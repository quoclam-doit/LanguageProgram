# Senior Frontend

Complete toolkit for senior frontend with modern tools and best practices.

## Core Capabilities

### 1. Component Architecture & Scaffolding
- Clean React 19 / Next.js component patterns with strict TypeScript typing.
- State management isolation (Local `useState`, TanStack Query for server state, Zustand for global UI state).
- Performance optimization: Avoid unnecessary re-renders, use Motion values for high-frequency updates.

### 2. Frontend Best Practices
- Accessible WCAG AA standards (contrast, focus states, keyboard navigation).
- Modern styling with Tailwind CSS v4, custom CSS variables, responsive mobile-first layouts (`min-h-[100dvh]`).
- Bundle optimization: Dynamic imports, code-splitting, asset preloading.

### 3. Modern UI/UX Engineering
- Production-grade micro-interactions, smooth physics, scroll parallax, and 3D animations.
- Clean error boundary handling and loading skeletons.
